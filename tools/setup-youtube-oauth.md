# 유튜브 연동 설정 (모두 무료)

두 가지가 있습니다. **1번만 해도 검색·타채널 분석·인기 쇼츠는 다 됩니다.**
내 채널의 비공개 통계까지 보려면 2번을 추가로 하세요.

---

## 1. YouTube Data API 키 (필수 — 검색/채널분석/인기쇼츠)

1. https://console.cloud.google.com 접속 → 프로젝트 만들기 (이름 아무거나)
2. 좌측 메뉴 **API 및 서비스 → 라이브러리** → "YouTube Data API v3" 검색 → **사용 설정**
3. **API 및 서비스 → 사용자 인증 정보** → **사용자 인증 정보 만들기 → API 키**
4. 만들어진 키를 복사 → 앱의 **API 키** 메뉴 → YouTube Data API 칸에 붙여넣고 저장
5. **연결 테스트** 버튼으로 확인

### 무료 한도
하루 10,000유닛이 무료로 주어지고 매일 리셋됩니다. 초과해도 과금되지 않고 그날 요청이 거부될 뿐입니다.
- 키워드/채널 검색: 100유닛 (하루 100회)
- 인기 쇼츠·영상 정보·채널 분석: 1~3유닛 (거의 무제한)

앱이 사용량을 상단에 표시하고, 같은 요청은 1시간 동안 캐시해 낭비를 막습니다.
검색보다 **인기 쇼츠 탭이 100배 저렴**하니 탐색은 그쪽을 먼저 쓰는 편이 좋습니다.

---

## 2. 구글 계정 연결 (선택 — 내 채널 비공개 통계)

시청 지속시간, 트래픽 소스, 영상별 성과 등 유튜브 스튜디오에서만 보이는 지표를 가져옵니다.
읽기 전용 권한만 요청하며 역시 무료입니다.

1. 위 1번과 같은 프로젝트에서 **API 및 서비스 → 라이브러리** →
   "YouTube Analytics API" 검색 → **사용 설정**
2. **OAuth 동의 화면** 설정 (아직 안 했다면):
   - User Type: **외부** 선택 → 앱 이름/이메일만 채우고 저장
   - **테스트 사용자**에 본인 구글 계정(채널 소유 계정)을 추가 ← 이걸 빠뜨리면 로그인이 거부됩니다
3. **사용자 인증 정보 만들기 → OAuth 클라이언트 ID**
   - 애플리케이션 유형: **웹 애플리케이션**
   - **승인된 리디렉션 URI**에 아래 주소를 정확히 추가:
     ```
     http://localhost:4310/api/youtube/oauth/callback
     ```
4. 생성된 **클라이언트 ID**와 **클라이언트 시크릿**을 앱의 **API 키** 메뉴 하단
   "구글 계정 연결" 칸에 입력하고 저장
5. **구글 계정 연결** 버튼 클릭 → 새 창에서 구글 로그인 및 권한 허용
   - "이 앱은 확인되지 않았습니다" 경고가 나오면 **고급 → (앱 이름)(으)로 이동** 클릭
     (본인이 만든 앱이라 정상입니다)
6. "구글 계정 연결 완료"가 뜨면 창을 닫고 앱의 **유튜브 리서치 → 내 채널 분석** 탭으로 이동

### 연결 해제
API 키 메뉴에서 "연결 해제"를 누르면 저장된 토큰이 삭제됩니다.
구글 계정 쪽에서도 지우려면 https://myaccount.google.com/permissions 에서 앱을 제거하세요.

---

## 자주 걸리는 문제

| 증상 | 원인 / 해결 |
|---|---|
| `403 accessNotConfigured` | 라이브러리에서 API 사용 설정을 안 함 → 1-2단계 확인 |
| `redirect_uri_mismatch` | 리디렉션 URI 오타 → `http://localhost:4310/api/youtube/oauth/callback` 정확히 |
| 로그인 시 "액세스 차단됨" | OAuth 동의 화면의 **테스트 사용자**에 본인 계정 미등록 |
| `refresh_token을 받지 못했습니다` | 이전에 이미 권한을 준 계정 → https://myaccount.google.com/permissions 에서 앱 제거 후 재시도 |
| 쿼터 초과 | 다음 날 자동 리셋. 그전까지는 인기 쇼츠 탭(1유닛) 활용 |
