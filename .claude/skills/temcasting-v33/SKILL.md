# 템캐스팅 대본 교리 v3.3

레퍼런스 10개 채널 상위작 전사 분석(2026-08-18)과 **발행 20편 원장** 실측에서 나왔다.
근거는 인상이 아니라 숫자다 — `아직도 힘들게 닦으세요?`로 연 편이 563회·계속시청 12.4%로
채널 최하위였고, 금지 명령형(`이제 양면테이프 쓰지 마세요`)과 서사형 훅이 상위를 차지했다.

**여기 적힌 실격 조건은 앱이 기계로 검사한다**(`shared/doctrine.ts`). 하나라도 걸리면
요청서 반영이 거부되므로, 통과할 수 없는 대본을 쓰면 되돌아온다.

---

## 절대 제약 두 가지

### 1. 음성 = 자막

나레이션과 화면 자막은 **글자 하나까지 같다.** `narration`과 `subtitle`에 같은 문장을 쓴다.

- 자막에만 넣는 정보 없음 (스펙 바·보조 텍스트 금지)
- 음성에만 있는 정보 없음 (전 문장 자막화, 발췌·요약 금지)
- **말하지 않을 것은 화면에도 없다.** 스펙은 설명란·고정댓글로 뺀다

### 2. 화자는 남자

```
❌ 시어머니 / 시누이 / 시댁 / 언니 / 오빠 / 남편
✅ 장모님   / 처제·처형 / 처가 / 누나 / 형   / 와이프
```

한 편 안에서 처가 계열과 본가 계열을 섞지 않는다.

## 5블록 구조

씬마다 `block`에 아래 값을 넣는다. **표시가 없으면 선행 구간을 잴 수 없어 반려된다.**

| 블록 | `block` 값 | 역할 | 필수 |
|---|---|---|---|
| ① 훅 | `hook` | 0~3초. 8종 중 택1. 제품·브랜드·기능 언급 0 | ● |
| ② 손실 | `loss` | 돈·시간·몸을 잃을 뻔한 상황 | ● |
| ③ 정보원 | `source` | 제3자가 알려줌 | ○ |
| ④ 제품 + 기능 | `product` | 한 문장 진입 + 동작 원리 1~2개 | ● |
| ⑤ 클로징 | `closing` | 결과 상태 / 조언 / 미련 | ● |

### 선행 구간은 비율이 아니라 절대 초수다

| 러닝타임 | 선행(①②③) |
|---|---|
| 17~19초 | **5~8초** |
| 20~23초 | **8~12초** |
| 24~26초 | **12~16초** |

상위 4편(1,254만·197만·183만·143만)이 전부 선행 10~16초다.
**「선행을 잘라 제품을 빨리 꺼내는 게 유리하다」는 통념은 표본에서 지지되지 않는다.**

## ① 훅 8종

| 유형 | 형태 | 표본 |
|---|---|---|
| **대사 인용** | 남이 나에게 한 말을 그대로 | **1,254만** |
| 금지 명령 | 이제 ~쓰지 마세요 | 143만 |
| 판정 선언 | ~하면 돈낭비네요 | 197만 |
| 안도 감탄 | 와, 이것 때문에 살았어요 | 183만 |
| 트렌드 전언 | 요즘 ~이게 유행이래요 | 109만 |
| 감정 선언 | ~진짜 얄미워 죽겠어요 | 102만 |
| FOMO | 이걸 나만 몰랐네요 | 70.8만 |
| 놀람 질문 | 이게 ~에 있다고요? | 53만 |

**대사 인용형이 최고 성과다.** 남의 말을 그대로 옮기면 시청자가 상황을 재구성하느라
이탈하지 못한다. 훅 유형은 **직전 편과 겹치지 않게** 고른다 (요청서에 직전 편이 적혀 온다).

## ② 손실 — 이 스킬의 핵심

100만 이상 상위 4편 **전부**에 금전 손실 위협이 있다.

| 유형 | 예시 |
|---|---|
| **금전** | 견적 / 보증금 / 원상복구비 / 업자 부름 |
| 시간 | 대기 몇 달 / 매번 몇 분씩 |
| 신체 | 허리 / 손목 / 무릎 |

금전이 가능하면 금전을 쓴다. 감정 반응 한 문장을 붙이면 강해진다 — "머리가 하얘졌습니다".

## ③ 정보원 (선택)

제3자는 ①의 갈등 인물이 아니라 **④ 직전의 정보 출처**다.

> "인테리어 하는 형한테 물어보니…" / "옆집 입주 청소 사장님께 여쭤봤더니…"

인물 풀: 엄마·아빠(주방·공구) / 장모님·장인어른(청소·수리) / 와이프(거실·침실) /
형·누나·동생(현관·수납·자취) / 처남·처제(신혼) / 선배·후배(차량·가전) / 친구(전 카테고리) /
**집주인(전세·무타공 — 손실 서사와 결합력 최고)** / 설치기사 / 옆집.

동일 인물 연속 2편 초과 금지, 10편 중 3회 초과 금지. 편당 최대 2명.

## ④ 제품 + 기능

한 문장으로 진입하고 동작 원리 1~2개를 잇는다. **스펙 나열 금지.**

```
✅ "붙어 있을 땐 엄청 단단한데 떼어낼 땐 자국이 없더라고요"
❌ "폭 32센치에 층고 29센치라 전자레인지도 들어갑니다"
```

## ⑤ 클로징

| 유형 | 예시 |
|---|---|
| 결과 상태 | "속이 다 시원하고 방 안 공기도 쾌적해졌습니다" |
| 조언 + 효용 | "전세 사시는 분들 미리 챙겨 두세요. 멘탈 지켜줍니다" |
| 미련 표명 | "진작 알았으면 벽지 뜯길 일도 없었을 텐데" |

**질문으로 댓글을 유도하지 않는다.** 광고 어법이라 이탈을 부른다.
CTA를 쓴다면 반드시 **지정 키워드**로 — "댓글에 선반 남겨 주세요"(○) / "궁금한 점 남겨주세요"(✗).

## 분량 — 글자수가 아니라 **음절수**다

공백·기호·숫자·영문을 빼고 **한글 음절만** 센다. 기준 **6.53 음절/초**(허용 6.5~8.0).

| 러닝타임 | 분량 |
|---|---|
| 17초 (최소) | 약 112음절 |
| 22초 (기본) | 약 144음절 |
| 29초 (최대) | 약 189음절 |

**17~29초**를 지키고 **29초를 넘기지 않는다**. **189음절을 넘지 않는다** —
넘으면 낭독이 잘리거나 배속이 부자연스러워진다.

숫자는 앱이 계산한다 (`shared/constants.ts`의 `TARGET_SEC_BY_MENU`·`syllableBudget`).
배속을 바꾸면 이 표도 따라 바뀌므로 요청서에 적힌 숫자를 우선한다.

**자막 1장 = 11~16음절 / 1.6~2.3초.** 절 단위로 끊되 각 조각이 자연스러운 구어일 것.

```
❌ "평소에는 내려서 안전간 역할을 하다가 필요할 때는 앞으로 펼쳐서 빨래를 넣을 수 있거든요"
✅ "평소엔 내려두면 안전간이고요" / "필요할 때 앞으로 펼치면" / "빨래가 쭉 들어가더라고요"
```

🔴 **씬 하나에 문장 하나.** 음성 합성이 씬 단위로 돌기 때문에 두 문장을 넣으면 뒷문장이
잘려 나가는데, 소리가 안 나는 게 아니라 **짧게 끝나서** 조용히 지나간다.

---

## 숫자 규칙

| 허용 | 금지 |
|---|---|
| 손실 금액 (삼십만 원) | 치수 (32cm·삼십이센치) |
| 대기 시간 (두 달) | 하중 (오백킬로) |
| 가격 감각 (만 원도 안 하는) | 색상 개수 |

**아라비아 숫자를 쓰지 않는다.** 음성=자막이라 화면 글자가 곧 낭독인데 「32」를 TTS가
어떻게 읽을지 보장되지 않는다. 허용된 손실 금액도 「삼십만 원」으로 적는다.

## 문체

### 어미를 번갈아 놓는다 — AI 티의 실체다

| 규칙 | 왜 |
|---|---|
| 인접 씬이 같은 어미로 끝나지 않는다 | 같은 소리가 붙으면 즉시 티가 난다 |
| 종결어미 3연속 금지 | 마침표가 연달으면 카탈로그 낭독이 된다. 사이에 **연결어미**를 넣는다 |
| 어미 종류 4가지 이상 | 10문장이면 10가지가 이상적이다 |
| `~더라고요` 2~3회 | 2회 미만은 실격, 4회부터는 그 어미 자체가 티가 난다 |

```
❌ …보여요. / …밭이에요. / …끈적해요. / …갔어요.        ~요 4연속
✅ …가 보면 / …했거든요. / …밭인데 / …끈적하고요. / …휑하더라고요.
```

**문어투를 입말로 바꾼다.** 사람은 「상부장」이라 안 하고 「위」라고 한다.

### 금지

```
2인칭 질문   ~하시나요 / ~이신가요 / ~하셨죠 / ~고민이세요 / ~세요?
평가 형용사  꿀템 / 역대급 / 미친 / 신박 / 강추 / 괴물 / 끝판왕
광고 어법    지금 바로 / 놓치지 마세요 / 이런 분들께 추천 / 필수템
```

**2인칭 명령형은 허용한다.** 훅과 클로징에서 작동한다 —
"이제 양면테이프 쓰지 마세요"(143만) / "전세 사시는 분들 미리 챙겨 두세요"(1,254만).

### 사건 진실성

실제 경험만. 시점 압축·인물 익명화·대사 재구성은 허용, **사건 창작은 금지.**
실제 경험이 없으면 ②를 인물 없이 "내 상황"으로만 구성한다.

## 실격 조건 (앱이 기계로 검사한다)

- [ ] 음성과 자막 불일치
- [ ] 자막 1장이 16음절 초과
- [ ] ② 손실 블록에 금전·시간·신체가 없음
- [ ] 선행 구간이 러닝타임 연동 표를 벗어남
- [ ] `block` 표시 없음 / ①②④⑤ 중 빠진 블록
- [ ] 공개(④) 전 블록에 제품을 확정시키는 명사
- [ ] 2인칭 질문형 / 평가 형용사 / 광고 어법
- [ ] 스펙 단위(cm·kg·센치) 또는 아라비아 숫자
- [ ] 여성 화자 호칭
- [ ] `~더라고요` 2회 미만
- [ ] 러닝타임·총 음절·발화 속도가 예산 밖
- [ ] 인접 씬 같은 어미 / 종결어미 3연속 / 어미 종류 4가지 미만

3회 재작성 후에도 미달이면 **제품 부적합 판정 → 교체 권고.**

## 산출물

`script.json` 하나. 씬마다 `sceneId` · `narration` · `subtitle`(나레이션과 동일) ·
`block` · `clipRef`를 넣는다. 소재 클립이 주어졌다면 각 씬에 쓸 클립과 구간을 지정한다.

```json
{
  "version": 1,
  "title": "집주인이 원상복구 말했을 때",
  "scenes": [
    {
      "sceneId": "s1",
      "block": "hook",
      "narration": "나가실 때 원상 복구해 주세요",
      "subtitle": "나가실 때 원상 복구해 주세요",
      "clipRef": { "clipId": "c1", "suggestedSegment": { "in": 2.0, "out": 3.8 } }
    }
  ],
  "notes": "훅 유형: 대사 인용 / 손실: 금전 / 정보원: 형"
}
```

작성 전에 설계를 한 줄로 정리한다 — **훅 유형 / 손실 유형 / 정보원 / 클로징 유형 /
러닝타임 n초 · 선행 n초 · 총 n음절.** 음절수는 눈대중하지 말고 센다.

### 요청서로 실행할 때

요청서 폴더의 `result/`에만 쓴다. `job.json`·`packet.json` 같은 상태 파일은 서버 전용이라
**건너뛴다.** 산출물을 다 만든 뒤 마지막에 `result/.done` 빈 파일을 만들면 서버가 감지해
검증하고 반영한다.
