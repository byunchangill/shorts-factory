SG/GJ/GL/BS에서 대안 3개를 제시한다.

003 싱크대 찌든때 필름이 569회로 죽은 이유가 이것이다. 덮기만 하는 제품은 변화가 밋밋하다.

```
✅ 통과: 롤러가 지나가며 타일 색이 뒤집힘 / 줄눈이 하얗게 살아남 / 서랍이 통째로 기움
❌ 거절: 스티커를 덮음 / 냄새가 사라짐 / 사용감이 좋아짐
```

## 5. 시리즈 캐릭터

벤치마크 채널은 **"집주인"이라는 고정 악역 하나로 5편**을 뽑았다(99.8만·59만·22.3만·11.4만·2.1만).
템캐스팅은 편마다 엄마·누나·친구가 바뀌어 축적이 없었다.

**주력 캐릭터: 집주인.** 설명란에 `[집주인 시리즈 ②]` 형태로 넘버링한다.

보조 캐릭터는 소재가 전세와 무관할 때만 쓴다. 한 번 쓴 캐릭터는 로그에 기록해
같은 캐릭터가 3편 연속 나오지 않게 한다 (집주인 제외 — 집주인은 연속 허용).

```
집주인   — SG 전 소재, 퇴거·원상복구 (주력, 연속 허용)
형 / 누나 / 동생 — 남의 집 관찰 시
장모님 / 어머니   — GL 생활 관리법
관리사무소 / 업체 — 공용부·견적 갈등
```
