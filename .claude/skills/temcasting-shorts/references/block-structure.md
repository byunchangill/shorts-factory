# 5블록 구조 — 문장 패턴 라이브러리

이 니치 상위작 5편(385만·194만·108만·99.8만·59만)에서 역산한 골격이다.
5편 전부 예외 없이 이 순서를 따른다.

---

## ① 훅 — 재생의 8~10%

**목적**: 무엇에 대한 얘긴지 알려주지 않은 채로 멈춰 세운다.

### 두 가지 유형만 쓴다

**유형 A — 금액 붙은 금지형**
```
"[품목] [금액] 주고 절대 [행위]하지 마세요."
"[금액] 주고 [행위]하기 전에 이거 보세요."
```
> "팬트리 200만 원 주고 절대 시공하지 마세요"
> "여러분 이거 모르고 다이소 가서 돈 날리지 마세요"

**유형 B — 1인칭 감정 반응**
```
"[인물] 때문에 진짜 [감정어]."
"[인물] 집 갔다가 진짜 [감정어]."
```
> "동생 집에 갔다가 진짜 충격받았어요"
> "장모님 때문에 진짜 깜짝 놀랐어요"
> "와, 이거 정말 대박이에요"

### 금지

- **제품명 0개.** 하나라도 들어가면 궁금증이 소멸한다.
- 질문형 훅 금지. (`~하세요?` — 기존 최저작 560회가 이 형태였다)
- `필수 시청`, `주목` 같은 지시어 금지. (기존 1,243회 편이 이 형태)

---

## ② 문제·갈등 — 재생의 32~49% (목표 38%)

**이 채널에 통째로 빠져 있던 블록이다.** 기존 10편은 여기를 20~22%만 썼다.

**철칙: 이 구간에 제품이 등장하지 않는다.** 화면에도, 나레이션에도.

### 3단 전개

```
1) 상황 개시   — 언제·어디서
2) 대립 인물 등장 — 집주인 / 가족 / 업체
3) 화자 측 불이익 확정 — 돈·시간·사생활·원상복구비
```

> 페인트(99.8만):
> "이번엔 구축 전세로 이사 갔는데 타일 상태가 생각보다 너무 더럽더라고요."
> → "집주인한테 얘기했더니 우린 돈 없으니 본인 돈으로 고치라고 해서"
> → "**열 받아서 머리 싸매고 있었는데**"

> 커튼필름(385만):
> "저층에 살고 있는데 밖에서 집안이 다 보이니까 늘 커튼 치고 살았거든요."
> → "커튼을 안 치면 지나가는 사람들이 힐끔 쳐다보고"
> → "**아내랑 아이들만 집에 있는 날도 많아서**" → "시공 알아봤더니 너무 비싸더라고요"

### 감정어 사전 (B3 채점 대상 — 2개 이상 필요)

```
열받아서 / 어이가 없어서 / 진짜 충격받았어요 / 깜짝 놀랐어요
머리 싸매고 있었는데 / 서운할 뻔했어요 / 눈앞이 캄캄했는데
```

### 죽은 문장 (기존 10편에서 실제로 쓰인 것들 — 재사용 금지)

```
❌ "친구집 벽에 이게 붙어 있더라고요"      — 화자에게 아무 일도 안 일어남
❌ "물어보니 공구는 망치 하나였대요"        — 6초에 답을 줘버림
❌ "누나 집 갔다가 현관에서 이걸 봤는데"    — 구경만 함
```

## ③ 해법 + 효용 — 재생의 34~54%

### 진입: 반드시 제3자 권위가 연다

```
"[직업/전문성] [관계]가 이걸 [추천/알려]줬는데"
```
> "페인트 회사 다니는 친구가 이걸 추천해 줬어요"
> "정리 전문가인 지인이 이걸 추천해 줬는데"
> "단골 세탁소 사장님 비법인 이거 한두 스푼 풀어서"

**해법 공개 시점은 재생의 40% 이후.** 검증 구간은 40~57%다.

### 진입 직후 2차 훅

정체를 공개한 직후 곧바로 새 궁금증을 심는다. 이 채널 최고 지속률(64%) 영상의 유일한 차이다.

```
"근데 더 신기한 건"  /  "근데 진짜는 따로 있는데"  /  "근데 이게 끝이 아니에요"
```

### 효용 3연타 + `~까지` 보너스

```
효용1 (설치/사용 간편) → 효용2 (핵심 성능) → 효용3 (공간/시간) → 보너스 "~까지"
```
> "물만 칙칙 뿌리고 붙이면 끝인데 / 안에서는 잘 보이는데 밖에서는 안 보이고 /
> 자외선 차단에 **단열까지** 돼서"

> "물 뚝뚝 흘리며 옮길 일도 없고 / 허리 숙여서 넣고 뺄 필요도 없고 /
> 자리도 많이 안 차지하고 / 과일 야채 **세척까지** 된다니까"

### 금지

- **스펙 나열 금지.** "8가지 벽면에 붙고 깊이 15cm" 같은 카탈로그 문장은 이탈을 만든다.
  숫자는 쓰되 **불편이 사라지는 방식**으로 번역한다.
  `깊이 15cm` → `한 뼘도 안 나와서 지나다닐 때 안 걸려요`
- 제품명 노출 금지. 계속 `이걸`이다.

## ④ 댓글 CTA — 재생의 8~17%

**상위작 5편이 5편 모두 이걸로 끝난다.** 이 채널에 없던 유일한 구조물이다.

### 2단 구성

```
1) 감정 회수 — 제목의 감정을 되받는다
2) 댓글 요청 — 유일 키워드 지정
```

> "집주인이 웃으면서 깨끗하게 써 달라고 부탁을 하는데 어이가 없어서 그냥 씹었네요.
>  욕실 페인트 정보는 **댓글로 남겨 주세요**"

> "저만 허리 숙여가며 설거지한 기분인데 **'식세기' 남겨 주세요**"

> "집주인도 공짜로 두고 가라고 하시는데 **안 돼.**" ← 펀치라인형 (짧을 때)

### 왜 링크가 아니라 댓글인가

이 채널의 1순위 병목은 전환이 아니라 **확산**이다. 조회 1.4만에 실제 댓글이 0개였다.
댓글은 좋아요보다 강한 시그널이라 1차 테스트 풀을 뚫는 문지기 역할을 한다.
링크를 바로 주면 댓글이 안 달린다. **답글로 보낸다.**

### 금지

- 정보 추가로 끝내기 금지. (`친구가 욕실에도 달았대요` — 회수가 아니라 보고다)
- 일반화 정리로 끝내기 금지. (`좁은 집은 이런 게 공간을 살려줍니다`)
- CTA 없이 끝내기 금지. **채점 A4 10점 전액 손실.**
