## 1. 제목

### 규칙

| 규칙 | 이유 |
|---|---|
| **훅과 다른 문장** | 제목이 훅을 미리 소비하면 안 된다. 벤치마크도 제목은 감정, 훅은 상황으로 갈라둔다 |
| **해시태그 1개까지** | 쇼츠 피드는 약 40자만 노출. 기존 5~6개가 본문을 밀어냈다 |
| **제품명 미노출** | 하위 3편 전부 제목에 제품명이 있었다 |
| **15~25자** | 그 이상은 잘린다 |

### 검증된 유형

```
감정형   "집주인 때문에 어이가 없네요."          99.8만
호기심형 "이삿날 집주인이 궁금해 한 이유!"        59만
금지형   "커튼 당장 갖다 버리세요!"              385만
자격형   "식세기 있어도 허리 아픈 이유!"          194만
```

### 이 채널의 실제 성적

```
✅ 노출 CTR 11.5%  "엄마가 보자마자 하나 더 사라고 난리 난 주방템"  ← 제3자 반응
✅ 노출 CTR 6.9%   "좁은 방 필수템! 꺾이고 늘어나는 L자 책장…"
❌ 노출 CTR 1.5%   "싱크대 찌든때, 아직도 힘들게 닦으세요?"      ← 질문형
❌ 노출 CTR 1.6%   "전세집? 드릴 꺼내지도 마세요!"
❌ 노출 CTR 1.9%   "신발장인 줄 진짜 몰랐던 신발장"             ← 제품명 2회
```

**질문형과 제품명 노출이 CTR을 죽인다.**

## 2. 댓글 CTA

### 문안

```
[감정 회수 문장] + [정보는 댓글에 '{키워드}' 남겨 주세요]
```

### 키워드 규칙

- **편마다 유일한 단어.** 로그에서 중복 확인 후 확정한다.
- 2~4자 명사. 필터링해서 답글을 보내야 하므로 흔한 단어는 피한다.
- 소재를 그대로 쓰지 말고 한 겹 좁힌다.
  `페인트`(흔함) → `욕실페인트` / `필름`(흔함) → `창문필름`

### 고정 댓글

```
📌 제품 정보는 댓글에 '{키워드}' 남겨주시면 답글로 보내드립니다
이 영상은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.
```

**링크를 바로 걸지 않는다.** 링크를 주면 댓글이 안 달리고, 이 채널의 1순위 병목은
전환이 아니라 확산이다. 조회 1.4만에 실제 댓글 0개였다.

3편 운영 후 댓글 수와 실제 클릭을 비교해 재평가한다.

### 과거 방식 폐기

```
❌ "프로필 링크 클릭 후 011 검색"
```
22초 보고 나온 사람에게 2단계 탐색을 시키는 구조다. 클릭률이 사실상 0이었다.

## 3. 설명란 템플릿

```
[집주인 시리즈 ②]

{한 줄 요약}

📌 제품 정보는 댓글에 '{키워드}' 남겨주세요

{시공물인 경우} ※ 시공 전 임대인 동의를 권장합니다.

이 영상은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.

#{태그 8~12개}
```

### 태그 규칙

- **매 편 동일한 기본 태그 세트를 쓰지 않는다.** 기존 10편이 동일 23개를 돌려썼다.
- **타 채널 브랜드 금지.** 기존 태그에 `스펙먼저`가 남아 있었다. 발견 즉시 제거.
- 문의 메일도 채널 전용 주소로 통일한다. (기존 `specfirstkr@gmail.com` 잔존)
- 소재 고유 태그 5개 + 채널 공통 태그 5개 구성.

## 4. 고지 2종

| 고지 | 언제 | 위치 |
|---|---|---|
| 쿠팡 파트너스 | **전 편 필수** | 설명란 + 고정 댓글. 문안 통일 |
| 임대인 동의 권장 | 시공·부착물(SG 전 소재) | 설명란 + 영상 내 작은 자막 1컷 |

시공 고지를 빼지 않는다. 벤치마크 채널이 댓글 250개를 받는 이유의 절반이 원상복구 논쟁인데,
**논쟁은 확산에 좋지만 시청자를 실제로 곤란하게 만들면 채널 신뢰가 깎인다.**

카톡·문자 연출을 쓸 경우 실제 캡처처럼 위조하지 않는다. 각색임이 드러나는 수준으로만.

## 5. 엔드카드

**기존 10편에 하나도 없었다.** 스튜디오 기록상 `표시된 최종 화면 요소 0`, `클릭수 0`이다.
지속률 64%짜리 영상을 끝까지 본 536명이 아무 데도 못 가고 나갔다. 재방문 시청자 2명의 직접 원인이다.

- 구독 버튼 + 다음 영상 요소를 **매 편 삽입**한다.
- 기존 10편에도 **소급 적용**한다. 코드 한 줄 안 고치고 쓸 수 있는 유일한 레버다.

## 6. 업로드 리듬

| 항목 | 규칙 |
|---|---|
| 빈도 | **하루 1편.** 같은 날 2편 금지 |
| 시간 | KST 19:00~20:00 고정 |
| 물량 | 편수를 늘려 해결하지 않는다 |

물량 전략은 이 니치에서 결론이 나 있다. 하루 2편에 편당 21.9만 회인 채널이 있는 반면,
하루 4.8편에 편당 1,084회, 816편에 편당 1.1만 회인 채널도 있다.
**물량은 증폭기지 엔진이 아니다.** 구조가 안 잡힌 상태에서 편수를 늘리면 정체가 굳는다.
