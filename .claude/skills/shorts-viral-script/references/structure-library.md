# 조회수 구조 라이브러리

## 실측 성과 (첨부 데이터 69편)

같은 제품이라도 어떤 구조로 포장하느냐에 따라 결과가 갈린다. 아래는 실제 조회수 기준.

| 구조유형 | 편수 | 평균 조회수 | 최고 | 판단 |
|---|---|---|---|---|
| 가격·효용 충돌형 | 6 | 226만 | 859만 | **최강** — 가격 대비 효용이 상식을 깨면 1순위 |
| 비밀폭로/정체공개형 | 6 | 199만 | 740만 | **최강** — 숨겨진 사실이 있으면 1순위 |
| 국가·브랜드 프레임형 | 17 | 101만 | 554만 | 표본 최다, 안정적 |
| 타겟감정 자극형 | 7 | 84만 | 371만 | 특정 집단이 선명할 때 |
| 손해회피/위험경고형 | 5 | 83만 | 226만 | 잘못 사면 손해 보는 제품 |
| 권위·전문가 신뢰형 | 8 | 47만 | 244만 | 전문가가 쓰는 제품 |
| 반전 재평가형 | 15 | 37만 | 202만 | 무난하지만 평균은 낮음 |
| 집착·광기 디테일형 | 2 | 13만 | 22만 | 표본 적음, 신중히 |
| 이유궁금증/현상해석형 | 3 | 5만 | 7.5만 | **약함** — 단독으로 쓰지 않는다 |

**읽는 법:** "반전 재평가형"이 15편으로 많이 쓰였지만 평균 37만이다. 반대로 "가격·효용 충돌형"은 6편뿐인데 평균 226만이다. **많이 쓰인 구조가 잘 터지는 구조가 아니다.** 제품이 가격·효용 충돌이나 비밀폭로에 맞는지를 먼저 따진다.

## 구조 선택 기준

제품 특성 → 구조를 이 순서로 판단한다.

| 제품이 이렇다면 | 구조 |
|---|---|
| 가격 대비 효용이 상식을 깬다 (싼데 평생 쓴다, 비싼데 이유가 있다) | 가격·효용 충돌형 |
| 알려지지 않은 사실·비하인드·성분·제조 비밀이 있다 | 비밀폭로/정체공개형 |
| 특정 국가·브랜드의 기술이나 문화가 얽혀 있다 | 국가·브랜드 프레임형 |
| 특정 집단(자취생·직장인·수험생·부모)이 딱 걸린다 | 타겟감정 자극형 |
| 잘못 사면 손해·위험이 있다 | 손해회피/위험경고형 |
| 전문가·현직자가 실제로 쓴다 | 권위·전문가 신뢰형 |
| 겉보기와 실제가 다르다 | 반전 재평가형 |
| 제조 디테일에 대한 집착이 비정상적이다 | 집착·광기 디테일형 |

## 제목 공식 (실측 상위 사례)

`a`, `b`는 치환 슬롯이다. 공식만 가져오고 문장은 새로 쓴다.

### 가격·효용 충돌형
```
평생 쓸 수 있는 a          (859만)
평생 a가 필요없는 b        (361만)
도대체 누가 살까 싶은 a
```
`a`: 소모품이라고 생각했던 제품 / `b`: 그 제품이 대체하는 것

### 비밀폭로/정체공개형
```
해킹당해버린 a             (740만)
결국 a 유출된 b            (372만)
a만 몰래 먹는/쓰는 b       (244만)
결국 밝혀진 a의 진실
```
`a`: 브랜드·기업 / `b`: 그 안의 비밀

### 국가·브랜드 프레임형
```
a가 유독 b하기 힘든 이유    (554만)
a를 바꿔준 b               (325만)
a는 못 만드는 b            (290만)
a가 더 이상 b가 아닌 이유   (177만)
```
`a`: 국가·브랜드 / `b`: 상식과 다른 상태

### 타겟감정 자극형
```
a를 눈물나게 하는 b        (371만)
a가 환장하는 b
a들이 미쳐버린 b
```
`a`: 선명한 집단 (갤탭유저, 400개월, 자취생) / `b`: 제품

### 손해회피/위험경고형
```
모르고 샀다가 a하는 b      (226만)
함부로 a하면 큰일나는 b
무시했다가 큰코다치는 a
```

### 권위·전문가 신뢰형
```
a가 추천한 b               (8.5만)
요즘 a가 b하는 이유
a들이 몰래 쓰는 b
```
`a`: 신뢰를 주는 직군 / `b`: 의외의 제품 (치과의사 × 사탕처럼 충돌이 있어야 강하다)

### 반전 재평가형
```
일부러 a하게 만든 b        (202만)
a가 만든 b                 (15만)
a를 너무 좋아했던 b의 최후  (101만)
불편해서 잘 팔리는 a
```

### 집착·광기 디테일형
```
a 가득한 b
변태같이 만든 a
디테일에 미친 a
```

## 제목을 만드는 순서

무작위로 쓰지 않는다.

1. **제품 특징 분석** — 이 제품에서 상식과 어긋나는 지점이 무엇인가
2. **인간 심리 분석** — 그 지점이 어떤 심리를 건드리는가 (손해회피 / 호기심 / 집단 공감 / 열등감 / 비밀)
3. **구조 선정** — 위 성과표에서 이 제품에 맞는 상위 구조를 고른다
4. **공식 대입** — 해당 구조의 공식에 `a`, `b`를 채운다
5. **검증** — 제목만 보고 "왜?"라는 질문이 생기는가. 안 생기면 버린다

## 제목이 약한 신호

- 제품명이 그대로 들어가 있다 → 검색은 되지만 클릭은 안 된다
- 형용사만 바꾼 수준이다 ("좋은 청소기" → "훌륭한 청소기")
- 읽고 나면 내용을 다 안 것 같다 → 볼 이유가 없다
- 5개 후보가 서로 비슷하다 → 각도가 하나뿐이라는 뜻
