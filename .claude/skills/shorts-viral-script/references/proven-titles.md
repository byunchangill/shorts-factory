## 치환 규칙 (원문 표기)

**평생 쓸 수 있는 a**
- a : 보통 소모품인 제품

**해킹당해버린 a**
- a : 사람들이 좋아하던 브랜드 제품

**a가 유독 b하기 힘든 이유**
- a : 특정 시장, 카테고리
- b : 성공하기 어려운 결과

**결국 a 유출된 b**
- a : 모두가 알고 싶던 비밀
- b : 유명 브랜드

**a를 눈물나게 하는 b**
- a : 비교 열등감을 느낄 타겟
- b : 경쟁 제품용 액세서리

**평생 a가 필요없는 b**
- a : 기존 제품의 필수 소모품
- b : 반복 사용 가능한 제품

**a를 바꿔준 b**
- a : 거대한 인식, 이미지
- b : 작고 평범한 제품

**a는 못 만드는 b**
- a : 국가, 집단
- b : 특정 매력의 제품

**a만 몰래 먹는 b**
- a : 내부자, 전문가
- b : 따라 하고 싶은 비밀 레시피

**모르고 샀다가 a하는 b**
- a : 사용 실수로 생기는 손해
- b : 평범해 보이지만 위험한 제품

**일부러 a하게 만든 b**
- a : 제품 가치와 반대되는 특징
- b : 이유가 궁금한 제품

**a가 더 이상 b가 아닌 이유**
- a : 기존 이미지가 강한 브랜드
- b : 기존 정체성

**a의 지갑을 열어버리는 b**
- a : 문제 해결 욕구가 큰 구매자
- b : 아이 문제를 해결하는 제품

**a가 걸린 b**
- a : 특정 국가 사람
- b : 이미 너무 강한 기준을 가져버린 상태

**만나면 a해야 되는 b**
- a : 과장된 회피 행동
- b : 몰입도가 너무 강한 제품

**세상에서 가장 a한 b**
- a : 과장된 완성도
- b : 흔한 생활용품

**a를 뒤집어버린 b**
- a : 큰 시장, 국가
- b : 중독성 강한 제품

**a를 너무 좋아했던 b의 최후**
- a : 집착 대상
- b : 한 분야에 미친 사람

**a들이 놀란 이유**
- a : 전문 직업군 또는 외국인 집단

**a가 만든 b짜리 c**
- a : 비범한 사람
- b : 말도 안 되는 금액
- c : 너무 평범한 제품

**a 없는 b짜리 c**
- a : 있어야 할 기능
- b : 말도 안 되는 가격
- c : 제품

**실수로 공개된 a**
- a : 원래 숨겨져 있던 유명인의 비밀템

**진짜로 a해져버린 b**
- a : 걱정되는 변화
- b : 익숙한 대기업

**a들이 환장하는 b**
- a : 특정 덕후층
- b : 취향을 강하게 드러내는 제품

**밝혀져버린 a의 진실**

**a한 b**

**a가 싫어하는 b**

**한계를 알 수 없다는 a의 진화**

**무시했다가 a하는 b**

**a라고 의심받는 b**

**a도 쓴다는 b팁**

**은근 모르는 a**
