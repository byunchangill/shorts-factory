# 🏭 쇼핑쇼츠 팩토리

쿠팡 제품 기반 쇼핑쇼츠(9:16)를 반복 생산하는 로컬 웹앱.
웹 UI가 영상 처리(다운로드·정리·음성·조립)를 맡고, 대본·포맷 설계는 **AI 요청서**로 처리하는 반자동 파이프라인입니다.
Claude, GPT, 제미나이 중 **아무 AI나** 쓸 수 있습니다.

## 메뉴

- **해외영상 짜집기** — 쿠팡 상세페이지 파일 첨부 + 영상 URL 무제한 입력 → yt-dlp 다운로드 → 자막/이모지/워터마크 제거(1차: ffmpeg 크롭/블러/보간, 2차: AI 인페인팅) → 제품 맞춤 대본 → 컷 선택 → 음성 → 최종 조립
- **제품정보리뷰** — 채널 고유 포맷(훅·씬 구성·톤·브랜딩)을 먼저 설계하고, 그 포맷으로 반복 생산 (수익화 채널 특화)
- **유튜브 리서치** — 키워드/쇼츠 검색, 인기 쇼츠, 타채널 분석, 내 채널 분석(비공개 통계). 찾은 영상을 바로 작업 소스로 추가
- **API 키** — 유튜브·AI·타입캐스트 키 등록 및 연결 테스트

## 설치

```bash
# 1. 의존성
npm install

# 2. 미디어 도구 (필수)
pip install yt-dlp
# ffmpeg: https://ffmpeg.org/download.html (winget install ffmpeg / brew install ffmpeg)

# 3. AI 인페인팅 (선택 — 2차 워터마크 제거)
pip install iopaint    # 상세: tools/install-inpaint.md

# 4. 점검
npm run doctor
```

## 실행

개발할 때는 화면을 고치면 바로 반영되는 쪽으로:

```bash
npm run dev
# 웹 UI: http://localhost:5173  /  API: http://localhost:4310
```

그냥 **쓰기만** 할 때는 터미널이 필요 없습니다. 화면을 미리 빌드해 두면 서버 하나가
화면까지 내주므로 주소도 하나입니다:

```bash
npm start        # http://localhost:4310 — 화면·API 모두 여기
npm run app      # 화면을 다시 빌드하고 서버 실행
```

### 윈도우 — 아무것도 없는 PC에 설치하기

소스를 받을 필요도, git·Node를 미리 깔 필요도 없습니다. **파워셸에 한 줄만** 붙여넣으면
됩니다 (저장소가 공개라 로그인도 필요 없습니다).

```powershell
irm https://raw.githubusercontent.com/byunchangill/shorts-factory/main/tools/win/install.ps1 | iex
```

파일로 건네주고 싶으면 `tools/win/install.cmd`를 보내세요 — 더블클릭하면 같은 일을 합니다.

설치되는 자리는 이렇습니다.

```
%LOCALAPPDATA%\ShortsFactory\
  ├─ app\         소스 — 업데이트할 때 통째로 갈아끼운다
  └─ workspace\   작업 데이터·API 키 — 업데이트가 건드리지 않는다
```

**작업 데이터를 앱 폴더 밖에 두는 것이 핵심입니다.** 안에 두면 업데이트 한 번에
포맷·산출물·API 키가 전부 날아갑니다. 설치 스크립트가 `SHORTS_WORKSPACE`를 잡아줍니다.

설치가 끝나면 바탕화면 아이콘이 생기고 앱이 열립니다. 그 뒤로는 아이콘만 누르면 됩니다.

### 업데이트

아이콘을 누를 때마다 새 버전이 있는지 확인하고 **물어봅니다.**

- **예** → 받아서 갈아끼운 뒤 앱을 엽니다 (작업 데이터는 그대로)
- **아니오** → 지금 버전으로 그대로 엽니다
- 인터넷이 안 되면 조용히 넘어갑니다 — 업데이트 때문에 앱을 못 여는 일은 없습니다

개발자의 깃 클론에서는 이 확인을 하지 않습니다 (`.version` 파일 유무로 갈립니다).
소스를 직접 고치는 쪽은 `git pull`로 받으면 됩니다.

### 윈도우 — 이미 소스가 있을 때 아이콘만 만들기

```
tools\win\create-shortcut.vbs   ← 더블클릭
```

바탕화면에 아이콘 2개가 생깁니다.

| 아이콘 | 하는 일 |
|---|---|
| **쇼핑쇼츠 팩토리** | 서버를 창 없이 띄우고, 주소창·탭 없는 앱 창으로 화면을 엽니다 |
| **쇼핑쇼츠 팩토리 - 서버 끄기** | 백그라운드 서버를 종료합니다 |

- 이미 서버가 떠 있으면 다시 띄우지 않고 창만 엽니다
- 실행할 때마다 화면을 다시 빌드하므로(약 3~5초) 코드를 고쳐도 옛 화면이 뜨지 않습니다
- 크롬이나 엣지가 있으면 앱 창으로, 없으면 기본 브라우저로 엽니다
- 서버는 백그라운드라 창이 안 보입니다. 무슨 일이 있었는지는 `workspace/logs/server.log`
  또는 `npm run logs`

#### 필요한 프로그램은 알아서 깔립니다

아이콘을 누르면 **없는 것만** 자동으로 설치합니다 (`winget` 사용). 있으면 건너뛰므로
두 번째 실행부터는 이 과정이 순식간에 지나갑니다.

| 대상 | 설치 방법 |
|---|---|
| Node.js | winget `OpenJS.NodeJS.LTS` |
| ffmpeg · ffprobe | winget `Gyan.FFmpeg` |
| yt-dlp | winget `yt-dlp.yt-dlp` |
| 크로미움 (틱톡 소재) | `npx playwright install chromium` |
| 글자 검출 (자막 자리 자동 찾기) | `pip install rapidocr-onnxruntime` |
| Python 3.12 | winget `Python.Python.3.12` (iopaint용) |
| iopaint (2차 AI 인페인팅) | `pip install iopaint` |

- 설치가 필요한 때만 **검은 창이 잠깐 보입니다** — 몇 분 걸리는 작업이라 진행 상황이
  보여야 합니다. 다 끝나면 창이 닫히고 앱이 열립니다
- "이 앱이 장치를 변경하도록 허용하시겠습니까?" 가 뜨면 **예**를 눌러야 설치됩니다
- 설치 직후에도 그 실행에서 바로 쓸 수 있게 PATH를 다시 읽습니다 (`refresh-path.cmd`)
- `winget`이 없는 PC(윈도우 10 구버전)에서는 자동 설치 대신 직접 받을 주소를 안내합니다
- 한글 폰트는 윈도우에 기본 탑재라 따로 깔지 않습니다

**iopaint는 조금 다르게 다룹니다.** 선택 기능인 데다 PyTorch가 딸려 와 2GB가 넘습니다.

- 맨 **마지막**에 설치합니다 — 여기서 실패하거나 오래 걸려도 앱은 이미 쓸 수 있는 상태입니다
- 실패해도 앱은 정상 동작합니다. 1차 워터마크 제거(ffmpeg)는 그대로 됩니다
- 한 번 시도하면 `workspace/.iopaint-attempted` 표시를 남겨, 실패했더라도 **매번 다시
  붙잡지 않습니다**. 나중에 직접 깔려면 `tools/install-inpaint.md` 참고
- Python은 3.13이 아니라 **3.12**를 씁니다 — PyTorch 지원이 아직 안 따라온 경우가 있습니다

배포가 아니라 내 PC의 `localhost`입니다 — 밖에서는 접속되지 않습니다.

## 새 PC로 옮길 때 (소스를 고치는 쪽)

친구용 설치본(`install.ps1`)이 아니라 **개발용 클론**을 새 노트북에 앉히는 순서입니다.
프로그램 설치는 스크립트가 하고, 사람이 직접 옮겨야 하는 것은 `workspace/` 하나뿐입니다.

### 1. 소스와 프로그램

```bash
git clone https://github.com/byunchangill/shorts-factory.git
cd shorts-factory
```

윈도우면 `tools\win\setup.cmd`를 더블클릭합니다 — Node·ffmpeg·yt-dlp·크로미움·글자
검출·iopaint를 없는 것만 깝니다 (`winget` 필요, 30분쯤 걸립니다). 없으면 손으로:

```bash
npm install
npx playwright install chromium          # 틱톡 소재 (npm 설치만으로는 안 딸려 옵니다)
pip install rapidocr-onnxruntime         # 자막 자리 자동 찾기
pip install yt-dlp iopaint               # iopaint는 선택 (2차 제거 2순위)
```

**VSR만은 자동으로 안 깔립니다** (2차 제거 1순위). 홈 폴더 아래 `vsr` 또는
`video-subtitle-remover`로 받으면 앱이 알아서 잡습니다 — `tools/install-inpaint.md` 참고.

### 2. 작업 데이터 (`workspace/`)

깃에 올라가지 않습니다. **여기에 API 키와 지금까지의 작업이 전부 들어 있습니다.**
옛 PC에서 복사해 오면 새 PC가 그대로 이어집니다.

```powershell
robocopy C:\...\shorts-factory\workspace D:\옮길폴더\workspace /E /XD browser cache logs .trash
```

| 빼는 폴더 | 왜 |
|---|---|
| `browser/` | 크로미움 프로필(255MB). **도우인·샤오홍슈 로그인 세션이 여기 있으니** 로그인을 유지하고 싶으면 이것도 복사하세요. 안 하면 새 PC에서 다시 로그인하면 됩니다 |
| `cache/` `logs/` `.trash/` | 다시 생깁니다 |

꼭 필요한 것만 챙긴다면 `settings.json`(배속·그레이딩 등 조정값) ·
`secrets.json`(API 키) · `menu-a/` `menu-b/`(카테고리와 작업) 넷입니다.
`settings.json`에는 절대경로가 없어 그대로 옮겨도 됩니다 — 도구 경로는 PC마다 그때 찾습니다.

**클라우드 동기화 폴더에는 두지 마세요.** `secrets.json`과 `browser/`가 그대로 올라갑니다.

### 3. 확인

```bash
npm run doctor     # 도구가 다 잡혔는지 — 뽑힌 경로까지 보여줍니다
npm test           # 단위 테스트
npm run harness    # E2E 파이프라인 (합성 영상으로 1편을 실제로 만듭니다)
npm run dev
```

`workspace/`를 안 옮겼다면 `npm run seed`로 샘플을 심어 화면을 채울 수 있습니다.

## 다른 PC에서 열어볼 때

`workspace/`는 깃에 올라가지 않아 새 PC에서는 화면이 전부 비어 있습니다.
샘플 하나를 심어두면 눌러볼 것이 생깁니다.

화면에서는 **해외영상 짜집기 → 카테고리 → 새 영상 작업 → 샘플 사용하기**를 누르면 됩니다.
터미널에서는:

```bash
npm run seed     # 생활용품 카테고리에 샘플 작업 하나를 만들어 영상 분석 단계까지 진행
npm run dev
```

인터넷도 API 키도 필요 없고, ffmpeg가 없으면 없는 만큼만 건너뜁니다.
분석 다음 단계(존 편집·대본·컷·음성·조립)는 직접 눌러 시험하는 것이 목적이라 채우지 않습니다 —
화면만 빠르게 채우려면 `npm run seed -- --full`. 자세한 내용은 `samples/README.md`.

## 삭제하면 어디로 가나

카테고리·영상 작업의 삭제 버튼은 폴더를 **지우지 않고 `workspace/.trash/{메뉴}/` 로 옮깁니다.**
잘못 지웠다면 그 폴더를 원래 자리(`workspace/{메뉴}/`)로 옮기고 서버를 다시 띄우면 그대로 돌아옵니다.
정말 지우려면 `.trash`를 통째로 비우면 됩니다. 이미 내보낸 결과물 폴더는 삭제해도 남습니다.

## API 키 (필요한 것만)

앱의 **API 키** 메뉴에서 등록합니다. 키는 `workspace/secrets.json`에만 저장되고 깃에 올라가지 않습니다.

| 키 | 용도 | 없으면 |
|---|---|---|
| YouTube Data API | 유튜브 리서치 (무료 10,000유닛/일) | 리서치 메뉴 사용 불가 |
| Anthropic / OpenAI / Gemini | 요청서 API 자동 실행 | Claude Code 또는 복사·붙여넣기로 처리 |
| Typecast | 나레이션 음성 합성 | 씬별 음성 파일을 직접 첨부 |
| 구글 OAuth | 내 채널 비공개 통계 | 공개 데이터만 조회 |

유튜브 설정 절차: `tools/setup-youtube-oauth.md`

## 사용 흐름 (해외영상 짜집기 기준)

1. 대시보드 → 해외영상 짜집기 → **새 카테고리** (생활용품·주방 등)
2. 카테고리의 **지침** 탭에서 대본/영상 지침 작성, **제품자료** 탭에 쿠팡 상세페이지 캡처 첨부
3. **새 영상 작업**(= 영상 한 편) → 영상 URL 붙여넣기(무제한) → 다운로드
   - (샘플로 시험만 해보려면 같은 모달의 **샘플 사용하기**)
   - (또는 **유튜브 리서치**에서 영상을 찾아 "잡에 추가")
4. 클립마다 프레임 위에 제거 영역 드래그 → 적용할 프레임 구간 지정(**구간 자동 찾기**로 채울 수 있음) → **1차 제거** (필요시 AI 인페인팅)
5. **대본 요청서 발행** → 세 방식 중 하나로 실행 → 결과 자동 반영 → 승인/반려
6. 컷 선택 → 음성(타입캐스트 캐릭터 선택 또는 씬별 파일 첨부) → 사용 권리 확인 → **조립** → 검수
7. **완료 처리** → 제품 폴더로 자동 내보내기

## 산출물 저장 위치

작업이 끝나면 설정한 폴더(기본: 다운로드)에 제품명 폴더가 만들어집니다.

```
{내보내기 루트}/충전기/
├─ 최종영상/  충전기_1편_최종_v1.mp4
├─ 영상/      정리된 클립
├─ 음성/      씬별 mp3
├─ 대본/      대본.md, 대본.json, 자막.srt
├─ 이미지/    씬 이미지·썸네일
└─ 업로드킷/  제목·설명·해시태그
```

## 요청서를 다른 AI로 처리하기

요청서는 지침·제품정보·소재현황·산출물 명세가 모두 들어 있는 자기완결 문서입니다.

- **Claude Code**: 표시된 `/answer-job ...` 명령을 터미널에 붙여넣기
- **API 자동**: 키를 등록했다면 버튼 한 번으로 서버가 직접 호출 (형식이 틀리면 1회 자동 재시도)
- **복사/붙여넣기**: "프롬프트 복사" → 무료 GPT·제미나이 웹에 붙여넣기 → 답변을 "결과 붙여넣기"에 붙여넣기 (설명 문장이 섞여 있어도 자동으로 추출)

## 주의

- 해외 영상 재사용은 **원저작자 허락/라이선스 확인이 사용자 책임**입니다. 워터마크를 제거해도 저작권은 사라지지 않으며, 조립 전 권리 확인 체크가 필수입니다.
- 업로드 킷에는 쿠팡파트너스 공시문구가 자동 포함됩니다.
- 유튜브 API는 무료 한도 안에서만 동작하도록 쿼터를 추적·차단합니다 (초과 과금 없음).


### 하네스가 검증하는 것

`npm run harness`는 임시 작업공간에 서버를 띄우고, ffmpeg로 만든 **합성 영상**(가짜 워터마크·자막 포함)을
로컬 HTTP로 서빙해 yt-dlp가 실제로 받아오게 한 뒤 전 구간을 돌립니다. 25단계 약 16초.

다운로드 → 분석/프레임 추출 → 존 지정 → 1차 제거 → 요청서 왕복(붙여넣기 경로) → 대본 승인 →
컷 선택 → 음성 → 저작권 게이트 차단 확인 → 9:16 조립 → 완료 → 제품 폴더 내보내기 → 상태·감사로그 무결성

유튜브에서 남의 영상을 받지 않고, 실제 workspace도 건드리지 않습니다(`SHORTS_WORKSPACE`로 격리).
산출물을 눈으로 확인하려면 `npm run harness -- --keep`을 쓰면 임시 폴더가 남습니다.
API 키 없이 돌아갑니다 — 음성은 파일 첨부 경로로 검증하며, 타입캐스트 합성은 키를 등록한 뒤 UI에서 확인하세요.

> 이미 `npm run dev`가 떠 있으면 포트 충돌로 즉시 중단됩니다. 서버를 끄고 실행하세요.
