## 절대 제약

### 1. 음성 = 자막

나레이션과 화면 자막은 글자 하나까지 같다.

- 자막에만 넣는 정보 없음 (스펙 바·보조 텍스트 금지)
- 음성에만 있는 정보 없음 (전 문장 자막화)
- **말하지 않을 것은 화면에도 없다**

### 2. 화자는 남자

```
❌ 시어머니 / 시누이 / 시댁 / 언니 / 오빠 / 남편
✅ 장모님   / 처제·처형 / 처가 / 누나 / 형   / 와이프
```

한 편 안에서 처가 계열과 본가 계열을 섞지 않는다.

## 숫자 규칙

> 표본 10편에서 음성으로 발화된 숫자는 손실 금액(30만 원), 대기 기간(두 달), 가격대(만 원) 정도다. **치수·하중은 거의 나오지 않는다.**

음성=자막이므로 자막으로 우회할 수 없다.

| 허용 | 금지 |
|---|---|
| 손실 금액 (30만 원) | 치수 (32cm) |
| 대기 시간 (두 달) | 하중 (500kg) |
| 가격 감각 (만 원도 안 하는) | 색상 개수 (7가지) |

**손실 숫자는 쓰고, 스펙 숫자는 뺀다.** 스펙은 설명란으로.

```
❌ "500kg까지 버티는 내구성이에요"
✅ "세탁기를 올려도 끄떡없더라고요"
```

## 문체

### 종결어미

| 어미 | 표본 빈도 | 용도 |
|---|---|---|
| **`~더라고요`** | **9/10** | 경험 전언. **필수** |
| `~하는 거예요` | 3/10 | 현장 재연 |
| `~거든요` | 2/10 | 배경 설명 |
| `~는 거 있죠?` | 2/10 | 놀람 공유 |

`~더라고요`는 편당 2회 이상. 나머지는 선택.

### 🔴 어미를 번갈아 놓는다 — AI 티의 실체다 (2026-08-20 추가)

위 표는 **어떤 어미를 쓰나**를 말하고, 이 절은 **어떻게 배치하나**를 말한다.
같은 어미가 이어지면 사람 말이 아니라 낭독이 된다. 반려 사유가 두 번 이것이었다
(magnetic-blind 「AI 티가 난다」 · upper-cabinet-lift 1차본).

| 규칙 | 왜 |
|---|---|
| **인접 문장이 같은 어미로 끝나지 않는다** | 같은 소리가 붙으면 즉시 티가 난다 |
| **종결어미가 3문장 연속이면 안 된다** | 마침표가 연달으면 카탈로그 낭독이 된다. 사이에 **연결어미**를 넣어 말이 흐르게 한다 |
| **어미 종류 4가지 이상** | 10문장이면 10가지가 이상적이다 |
| `~더라고요` 는 2회 이상 **3회 이하** | 2회 미만은 실격, 4회부터는 그 어미 자체가 티가 난다 |

```
❌ 1차본   …보여요. / …밭이에요. / …끈적해요. / …갔어요. / …휑해요.     ~요 5연속
✅ 최종본   …가 보면 / …했거든요. / …밭인데 / …끈적하고요. / …갔더니 / …휑하더라고요.
```

**문어투를 입말로 바꾼다.** 사람은 「상부장」이라 안 하고 「위」라고 한다.

```
❌ 상부장에서 선반이 통째로 내려옵니다      ❌ 기름때에 절어서
✅ 위에서 선반이 쭉 내려오는데              ✅ 기름 튀니까
```

`scripts/check_script.py` 가 인접 중복·연속 길이·종류 수를 **자동으로 막는다.**
